# MoviPay — Frontend (Web)

Aplicação web do MoviPay, construída em **Next.js 14** (App Router) com React 18, Tailwind CSS, Framer Motion e Leaflet.

Para a visão geral do projeto (funcionalidades, arquitetura, backend, banco de dados e app mobile), veja o [README principal](../README.md).

## Rodando localmente

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`. Para detalhes de estrutura de pastas e rotas, veja [`PROJETO.md`](./PROJETO.md).
